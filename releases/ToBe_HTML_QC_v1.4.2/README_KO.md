# v1.4.2 QC에서 실제 검사한 To-be HTML

2026-11-13 · 파일 내용은 QC 당시 생성물과 동일합니다. 발견된 결함을 수정한 새 버전이 아닙니다.

## 열기

ZIP을 풀고 S13_CRM_ToBe_v1.4.2_QC_Full.html을 Chrome 또는 Edge에서 여세요. 인터넷 연결 없이 작동하도록 구성된 단일 HTML입니다. 회사 보안 정책으로 로컬 HTML 열기가 차단되면 허용된 브라우저 환경에서 확인하세요. 실제 QC 브라우저는 Chromium이며 Firefox·WebKit은 미검증입니다.

## 들어 있는 파일

- S13_CRM_ToBe_v1.4.2_QC_Full.html: 첨부 Excel·As-Is HTML의 원천357개 업무를 모두 반영한 전체 CRM 진단본. 이전 작성 To-be 설계205개 업무를 원천 행·업무명으로 정확 대응시켜 사용했습니다. 화면·원천 보존·저장 기능의 진단용이며, 새 v1.4.2 표 형식의 검증 오류388건이 남아 있습니다. 전체 업무 설계의 최종 납품본이 아닙니다. 이388건은 구버전 시험 설계의 형식 차이이므로 스킬 결함18건에 더해 세지 않았습니다.
- S13_CRM_ToBe_v1.4.2_QC_Sample.html: 같은 첨부 입력의 Brief 접수4개 업무로 현행 형식을 새 작성한 대표 검증본. 생성8명령·브라우저24화면을 실행했습니다. 설계 오류0, 문체 위반0이지만 검토6건·명칭경고1건이 있어 최종 업무 승인본은 아닙니다.
- SHA256SUMS.txt: QC 당시 파일과 내용이 같은지 확인하는 해시입니다.

## 확인할 위치

전체 CRM 파일에서 화면 As-Is → Lv.4 → 단계4(성과측정/최적화)를 선택하세요. 아래쪽 Global Data Transformation Center(데이터비즈니스3팀) 레인의 Monthly/Weekly 및 Daily 업무를 찾으세요. 각 수집·통합 업무와 리포트 작성 업무는 모두 있지만 두 업무를 잇는 화살표가 없습니다. 화면에 다 보이지 않으면 지도를 가로·세로로 이동하거나 확대/축소를 조절하세요.

대표 검증본에서는 To-be → Lv.6 → 흐름도 편집 → 박스 추가를 한 번 누르고 새 이름을 수정하지 않은 채 되돌리기를 눌러 보세요. 첫 번째에는 박스가 남고 두 번째에 없어지는 현상을 확인했습니다. 시험 뒤에는 저장하지 않고 파일을 다시 열면 됩니다.

원본 Excel·HTML을 다시 입력할 때 발생하는 저장 편집 무시, 행 대응 오류, 연속 업무 제외 등의 문제는 이 결과 HTML만 눌러서는 재현되지 않습니다. 별도 입력 사본과 생성 단계가 필요한 문제입니다. 보안 예외 문자열을 넣은 시험용 HTML은 이 묶음에 포함하지 않았습니다.

B7 잘림 경고는 실제 글자 소실로 확인되지 않은 검사 오탐입니다. 큰 지도의 스크롤 영역이나 기본 선 합침을 그 자체로 오류라고 해석하지 마세요.
